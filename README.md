# Supreme Crafting

Adds questionable crafting devices like 81x81 crafting table, or 128x128x128 furnace multiblock.
This mod has actually started like 2 years ago after I player Meatballcraft modpack, was just a weird idea at a time, but now I actually decided make it fully-featured and stable

## Features

- **81×81 Supreme Table** - 6,561-cell crafting grid with pan/zoom and partial-fill from EMI/JEI
- **Supreme Furnace** in three tiers (32³ / 64³ / 128³), smelting 1 / 8 / 64 items per tick at 4× fuel cost. Form multiblock by RMB with Supreme Wrench. Can use hatches for automation. Can be auto-built by furnace bomb, and quickly remove whole multiblock by Furnace Destroyer
- **Supreme Furnace Terminal** - remote access to the furnace (???)
- **Supreme wooden tools** - vanilla tools but with 100 blocks range (???)

## Dependencies

- Minecraft 1.21.1
- NeoForge 21.1.215+
- Architectury API 13.0.8+
- Has optional Patchouli guidebook support
- Has KubeJS support for `event.recipes.supreme_crafting.supreme_shaped(...)` and `supreme_shapeless`
